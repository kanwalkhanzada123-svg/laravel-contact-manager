# 🚀 PipelinePro CRM - Modern Lead & Sales Pipeline System

A full-featured Customer Relationship Management (CRM) and Lead Automation platform built with **Laravel**, **Tailwind CSS**, **Chart.js**, and **SortableJS**.

---

## 🌟 Key Features

* **📈 Real-Time Analytics Graph:** 7-day inquiry volume trends built with Chart.js.
* **📌 Interactive Kanban Pipeline:** Drag-and-drop lead stage management (*Pending → Discussion → Won Deals → Lost*) with instant AJAX persistence.
* **✉️ Direct Email Reply:** Integrated modal allowing administrators to send email responses directly to leads.
* **📝 Notes & Deal Management:** Set deal values ($), assign priority tags (Low/Medium/High), and record internal team notes.
* **📊 Live Metric Cards:** Instant counts for Total Leads, Pending, Discussion, Won Deals, and Today's Inquiries.
* **📥 CSV Data Export:** Single-click CSV export of all leads and notes for reporting.
* **🔐 Admin Authentication:** Secure auth protecting CRM records and management endpoints.

---

## 🛠️ Tech Stack

* **Backend:** PHP / Laravel
* **Frontend:** Blade Templates, Tailwind CSS
* **Data Visualization:** Chart.js
* **Interactivity:** Vanilla JS, SortableJS
* **Database:** MySQL / PostgreSQL
