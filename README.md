# 📬 Laravel Contact Manager & Admin Inbox

A modern, full-stack Laravel CRUD application featuring a responsive contact form and a dynamic admin inbox dashboard styled with Tailwind CSS.

---

## ✨ Features
* **Contact Submission:** Interactive form with client-side and server-side validation.
* **Inbox Dashboard:** Real-time messages table fetched from MySQL database.
* **Status Management:** Toggle messages between `Unread` and `Read` with visual status badges.
* **Message Deletion:** Delete individual entries securely using RESTful routes.
* **Responsive UI:** Clean, modern interface designed with Tailwind CSS.

---

## 🛠️ Tech Stack
* **Backend:** Laravel (PHP)
* **Frontend:** Blade Templates, Tailwind CSS
* **Database:** MySQL
